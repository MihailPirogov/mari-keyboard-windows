# Марийская раскладка 3.1 для macOS
© Михаил Пирогов, [PirogovLab](https://pirogovlab.ru/mariyskaya-raskladka-klaviatury/)

Русская ЙЦУКЕН + марийские буквы на клавише **Option** (как AltGr в Windows). Shift + Option — заглавные. Cmd+C/V/Z работают как обычно.

## Установка
1. Распакуйте `MariKeyboard-3.1-macOS.zip`.
2. Правый клик по `install.command` → «Открыть» → «Открыть» (macOS спросит, т.к. файл скачан из интернета).
3. Скрипт скопирует `Mari.bundle` в `~/Library/Keyboard Layouts`, снимет карантин и сам включит раскладку (нужен swift из Xcode Command Line Tools; без него — см. п. 4).
4. Если в строке меню не появилась «Марийская»: выйдите из системы и войдите снова, затем Системные настройки → Клавиатура → Источники ввода → «Изменить…» → «+» → **«Другие»** → «Марийская» → «Добавить». (В списке русского языка её нет — macOS не знает марийский язык.)
5. Переключение — значок в строке меню или Ctrl+Пробел / Fn.

## Удаление
Запустите `uninstall.command` (или удалите `~/Library/Keyboard Layouts/Mari.bundle`) и перезайдите в систему.
