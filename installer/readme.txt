Марийская раскладка клавиатуры 3.1 для Windows 10/11
© Михаил Пирогов

Состав:
  kbdmari.dll  — драйвер раскладки (System32; для 32-битных программ — копия в SysWOW64)
  mari-layout.ps1 — регистрация раскладки и добавление её в список языков
  kbdmari.klc  — исходник раскладки в формате Microsoft Keyboard Layout Creator
  keymap.html  — схема раскладки

Ввод марийских букв: AltGr (правый Alt) + а, о, у, ы, н -> ӓ ӧ ӱ ӹ ҥ
(с Shift — заглавные: Ӓ Ӧ Ӱ Ӹ Ҥ). Выбор раскладки: Win+Пробел.

Как устроено (по умолчанию):
  Раскладка «Марийская» подключается к РУССКОМУ языку и ставится в нём ПЕРВОЙ,
  обычная «Русская» — второй. На панели задач «РУС». Ваши языки (English (US),
  русский) и их порядок не меняются, горячие клавиши тоже: языки переключаются
  как раньше (например, Ctrl+Shift), раскладки внутри русского — сочетанием
  для раскладок (обычно Alt+Shift) или Win+Пробел.
  Языковые пакеты не скачиваются, перезагрузка не нужна. Если раскладки не видно
  сразу — выйдите из системы и войдите снова.
  Другой вариант — под английским языком (ENG), английский первым:
  «Пуск» -> «Марийская раскладка» -> «Включить как раскладку английского языка».

Индикатор «МАР / РУС» (MariIndicator.exe):
  Windows показывает на панели задач только язык («РУС»), поэтому «Марийская»
  и «Русская» выглядят одинаково. Небольшой значок возле часов показывает
  «МАР» (малиновый), когда включена марийская раскладка, и «РУС»/«ENG»
  (серый) — для остальных. Ставится галочкой при установке (по умолчанию —
  да), запускается вместе с Windows. Если значок спрятан под стрелкой ^,
  перетащите его на панель задач. Правый щелчок — схема раскладки или
  «Закрыть индикатор»; снова включить — «Пуск» -> «Марийская раскладка» ->
  «Индикатор МАР-РУС». Без индикатора: щелчок по «РУС» показывает список с отмеченной
  раскладкой; можно также включить «Языковую панель» с текстовыми метками
  (Параметры -> Устройства -> Ввод -> Дополнительные параметры клавиатуры).

Скрыть системный индикатор языка (галочка при установке, по умолчанию — да,
  если ставится индикатор; для тихой установки отключить — /KEEPSYSINDICATOR):
  включается «Языковая панель рабочего стола» в скрытом виде, значок «РУС»
  Windows на панели задач пропадает, остаётся только «МАР / РУС». Alt+Shift и
  Win+Пробел работают. Полностью применяется после выхода и входа в систему.
  Прежние настройки сохраняются и возвращаются при удалении.

Проверка: «Пуск» -> «Марийская раскладка» -> «Проверить установку»
  (отчёт: %TEMP%\MariKeyboard-check.txt).

Экспериментальный режим «отдельный язык mhr» (только по выбору при установке
или MariKeyboard-Setup-3.1.exe /MODE=mhr) не рекомендуется: Windows 10/11
не знает марийский язык и может бесконечно показывать «Поиск языкового пакета».
Вернуться к обычному режиму: «Пуск» -> «Марийская раскладка» ->
«Включить как раскладку русского языка (по умолчанию)».

Флаги: в Windows 8/10/11 индикатор языка показывает только текст;
показ флага для обычной раскладки (не TSF-службы) системой не поддерживается.

Удаление: «Параметры» -> «Приложения» -> «Марийская раскладка клавиатуры»
(или «Программы и компоненты»).
Журнал установки: %TEMP%\MariKeyboard-setup.log
